Key Concepts:
1. Git Branching Model:
   - Branches are lightweight movable pointers to commits.
   - Fast-forward merge occurs when target branch is directly upstream.
   - True 3-way merge creates a merge commit with two parents.

2. Synchronization from Multiple Workstations:
   - Cloning into secondary directory simulates multi-developer workflow.
   - Local commits pushed to origin/main can be fetched and integrated via git pull.
